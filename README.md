Enterprise-grade **Zero-Trust Cryptographic Command Authentication Core (Rust)** paired with an automated **KVKK & GDPR PII Redaction Middleware (Python 3.13)** engineered by **BAYSOZ YAZILIM**.

## Architecture Overview
- **`rust_crypto_shield/`**: Memory-safe SHA-256 directive signing and tamper detection ensuring every autonomous agent command is cryptographically verified.
- **`python_kvkk_guard/`**: Real-time privacy filter scrubbing Turkish National IDs (TCKN), phone numbers, email addresses, and API credentials prior to external LLM transmission.
